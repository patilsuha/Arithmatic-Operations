# Arithmatic-Operations
Arithmetic Operations in C
📌 Project Description
This project is a simple Arithmetic Operations program developed using the C programming language. It performs four basic mathematical operations: addition, subtraction, multiplication, and division.

The main purpose of this project is to understand how to organize a C program using multiple source files and a header file. It demonstrates the use of functions, function declarations, return values, and compilation of multiple C files.

✨ Features
Addition of two numbers
Subtraction of two numbers
Multiplication of two numbers
Division of two numbers
Uses separate functions for each arithmetic operation
Demonstrates modular programming in C
📂 Project Structure
Arithmetic-Operations/
├── program1.c
├── program2.c
├── demo.h
└── README.md
program1.c: Contains the main() function, calls the arithmetic functions, receives their return values, and displays the results.
program2.c: Contains the function definitions for addition, subtraction, multiplication, and division.
demo.h: Contains the function declarations required to use the arithmetic functions in other source files.
README.md: Provides information about the project.
🛠️ Technologies Used
C Programming Language
GCC Compiler
Visual Studio Code or any C-compatible code editor
⚙️ How to Compile and Run
Step 1: Open a terminal in the project directory.

Step 2: Compile the source files using GCC.

gcc program1.c program2.c -o demo
Step 3: Run the program.

For Linux or macOS:

./demo
For Windows:

demo.exe
